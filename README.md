# OPPO Storage Cleaner

面向 OPPO / Android 手机的存储空间分析与清理工具。

## 项目状态

项目处于需求梳理阶段，尚未实现扫描或清理功能。

当前已确认的第一步：**先做空间分析，了解空间被什么占用，再决定如何清理。**

## 第一阶段目标

- 展示设备总容量、已用空间与剩余空间。
- 在实际可访问的范围内，分析文件类型、目录和大文件的占用。
- 明确区分已扫描内容、无权访问的内容与尚未解释的空间，不把未知空间直接视为垃圾。
- 用分析结果确定后续清理重点。

上述内容为待验证的目标，具体可获取的数据取决于设备系统版本、授权范围和最终实现方式。

## 待一起确定

- 工具形态：手机 App，或通过 USB / 无线调试连接手机的电脑工具。
- 设备型号、Android / ColorOS 版本，以及连接与授权方式。
- 首版分析报告需要展示的内容和验证方法。
- 后续是否支持重复文件识别、备份和用户逐项确认的清理。

## 初步原则

- 第一阶段只读取和分析，不删除或修改手机文件。
- 分析尽量在本地完成；公开仓库不收集个人文件、文件清单、聊天记录或设备备份。
- 后续清理需要展示具体对象和预计释放空间，并由用户确认。
- Android 对其他应用的私有数据存在访问限制，不能承诺扫描或清理所有缓存。

## 后续工作

先核实系统权限与设备能力，比较实现路线，再形成设计和开发计划。
